# C++ Notes

This repository documents my journey learning c++.

### Feature Of C++ Language
- Rich Library 
    - c++ inncorporates multiple built in arithmetic & logical function along with many built in libraries which make developent faster and convenient.

- Object-Oriented
    - OOP makes development & maintenance easier  

- Compiler Based
    - it means w/o compilations no c++ program can be executed. We need the compiler then we can execute the program.

- Extensible
    - c++ is extensible because of its easy and adaptable features.

- Recursion
    - c++ supports function backtracking which involves recursion, the process of recursion is called within another function for multiple numbers of times.

- Pointers
    - enables us to directly interract with the memory using the pointers. We use pointers in memory structure, functions, array, stack and etc.

- Structured
    - c++ supports structured programming

- Memory Management
    - it can both allocate and deallocate memory dynamically at any instance of time
